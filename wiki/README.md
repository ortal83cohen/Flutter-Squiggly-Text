# Project Wiki

This directory contains the project's research, implementation plans, decision records, and work summaries.

## Organization

- `research/` for technical investigations and external references.
- `plans/` for implementation and migration plans.
- `decisions/` for durable architecture and design decisions.
- `summaries/` for progress and completed-work summaries.

All wiki content must be written in English and use Markdown. Keep this file up to date as documents are added.
